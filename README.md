# AI Path — Study Planner

A lightweight, mobile-friendly progressive web app (PWA) for a student learning AI + robotics and preparing for university entrance tests in Pakistan.

## Features
- Daily checklist for maths, Python, test practice and review
- Learning roadmap from maths foundations through Python, AI, computer vision and robotics
- General test-prep checklist with target selectors for NUST NET, FAST, COMSATS, UMT and other universities
- Practice-session log
- Target university and expected test date tracker
- Saves progress in the current browser/device
- PWA manifest and service worker for Add to Home Screen and basic offline use

## Publish using GitHub Pages
1. Sign in to GitHub and create a new repository, for example `ai-path-study-planner`.
2. Upload all files in this folder to the repository's root (not the ZIP file itself).
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish the site. Open the published URL in Safari on your iPhone.

## Add to iPhone Home Screen
1. Open the published GitHub Pages URL in **Safari**.
2. Tap the Share button.
3. Choose **Add to Home Screen**. If shown, enable **Open as Web App**.
4. Tap **Add**.

## Notes
- This is a web app/PWA, not a native App Store app.
- Progress is stored locally in the browser. It does not sync automatically across devices.
- Test formats change. Always confirm the current syllabus and eligibility on the official university admissions website.
- For a future version, add verified official deadlines, links and specific syllabus details after choosing the target universities and admission cycle.
